# AWS S3 Static Website Hosting Lab

This repo documents a hands-on lab completed as part of the **AWS Cloud Computing Essentials** course on AWS Skill Builder / AWS Educate.

## What I did
- Reviewed and applied an Amazon S3 bucket policy
- Enabled static website hosting on an S3 bucket
- Configured public access to allow `GetObject`
- Hosted a simple static website using HTML files

## Architecture Overview
Users access the website via the S3 website endpoint, which retrieves objects from the S3 bucket based on the configured bucket policy.

## Key AWS Services
- Amazon S3
- IAM (bucket policy & access control)

## What I learned
- How S3 static website hosting actually works in practice
- How bucket policies control public access
- Why misconfigured access is a common cause of errors
